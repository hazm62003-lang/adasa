# عدسة (Adasa) - Assignment 14

1. حط ملف `posts.json` في `src/data/posts.json`
2. `npm install`
3. `npm run dev`

الصفحات: `/` الرئيسية، `/blog` المدونة (بحث + فلترة + Grid/List + Pagination)، `/blog/:slug` التفاصيل، وأي مسار تاني بيعرض 404.
البحث والتصنيف والصفحة والـ view محفوظين في الـ URL (مثلاً `/blog?category=إضاءة&page=2`).
